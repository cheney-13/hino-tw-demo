# HINO 台灣官網改版 DEMO

依 Figma「UI 設計提案」首頁與車款頁（桌機 1440 / 手機 390）製作的示意網頁。

- `index.html`：首頁
- `300.html`：300 系車款頁（首頁與選單內所有車款皆連到此頁）

互動：主選單車款下拉、手機選單、主視覺輪播、熱門車款 500 系子選單、卡片往上展開、頁內錨點導覽、選車比較、規格表、購車試算、專人聯繫／預約試乘表單流程（含簡訊驗證示意）。

> 文案與規格依 Figma 與 hino.com.tw；車主故事、價格、據點名稱等為示意資料，待客戶提供。

## 修改

頁面由 `build/build.py` 產生：

```
python3 build/build.py
```
